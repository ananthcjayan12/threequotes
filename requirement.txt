3kwotes MVP Development Brief
Product Name: 3kwotes
Goal: Build a working MVP that enables users to submit a business service request, receive a BOQ, and get quotes from verified vendors - all in one simple, guided experience.
Core MVP Features
- Landing Page: Clean homepage explaining what 3kwotes does and CTA to 'Get Quotes'
- Category Selector: Dropdown menu for 3 service categories: Printing, Accounting, Digital Marketing
- AI Assistant Interface: Chat-based interface that gathers inputs from the user and converts it into a BOQ
- BOQ Generator: Automatically generates a structured BOQ in PDF or text format
- Vendor Dispatch: BOQ gets automatically sent to 3 pre-selected vendors (via email for MVP)
- Response Handling: Vendors reply via email or through a form link
- Admin Panel (Basic): Admin dashboard to manage vendors, track inquiries, and assign vendor groups per category
Tech Stack (Recommended)
- Frontend: React.js / Next.js OR Webflow
- AI Chat Agent: GPT-4 API or Flowise/Typebot
- Backend: Node.js or Python
- Database: Firebase / Supabase
- Email: SendGrid / Mailgun
- PDF Generator: Puppeteer / DocuPilot
- Admin UI: Retool / Supabase Studio
User Journey (MVP)
1. User visits homepage
2. Clicks 'Get Quotes' and picks a service category
3. Interacts with AI chatbot to share details
4. BOQ is generated automatically
5. User confirms and submits
6. BOQ is sent to 3 verified vendors
7. Vendors respond via form or email
8. User receives quotes and decides whom to contact Deliverables (for MVP v1)
